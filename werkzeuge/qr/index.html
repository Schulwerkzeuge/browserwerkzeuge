Mit Logo wird immer die höchste Stufe verwendet.

Logos nur verwenden, wenn die Nutzung erlaubt ist.

Link oder Text eingeben …

Die Codes werden vollständig im Browser erzeugt; Links und Logos werden nirgendwohin übertragen. Anders als bei vielen Online-Generatoren enthält der Code direkt den eingegebenen Link und keine Umleitung über einen fremden Server. SVG eignet sich am besten für Arbeitsblätter und Plakate (in LibreOffice: Einfügen → Bild), da es verlustfrei skaliert. Jeden Code vor dem Drucken einmal mit dem Handy testen – besonders mit Logo.
